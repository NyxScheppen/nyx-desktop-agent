# 可复用经验教训

按改动风险查阅；这里只保留常见失败模式，不维护逐次修复历史或实现规格。新的同类教训合并到已有条目。

## 因果、事务与恢复

- 区分受理、核心提交、消费者完成和广播成功；提交后通知失败不能变成业务假失败。
- 先完成模型与外部准备，再短事务提交确定结果；数据库回滚不能恢复已经发生的网络或文件副作用。
- 原子边界要覆盖关联对象、事件和去重标记；恢复还需处理没有执行者的运行态。
- 重放先找已提交终局，恢复原身份、来源时间与结果，不重新生成、不重复扣减。
- 网络失败表示结果可能未知；未确认的副作用不能按普通失败自动重试。
- 关闭前停止准入并排空实际 writer，超时保留资源；取消也需清理尚未登记的连接和线程。

## 发现、来源与时间

- 新写入口要核对旧消费者，新消费者要核对全部旧来源；同类内容应在消费侧统一发现。
- 先过滤资格与来源，再截断候选；无匹配不能拿“最新一条”替用户决定。
- 去重、召回与归因依据真实来源和已存快照，不能用主题相近替代事实相同，注意否定、数字与语言差异。
- 原文、摘要、索引与事实各有用途；文中第一人称和模型推测不自动归给用户。
- 区分发生、采样、创建、接收和整理时间；未知时间不补造成现在，用户“今天”按本地自然日解释。
- 真实召回只统计实际进入最终上下文的内容，不能与去重强化共用计数；衰减从上次结算点计算。

## 异步界面与交互

- 角色、书籍和请求代数保护所有 success/error/finally、计时器与重试；A→B→A 也会有过期回包。
- 已提交终局优先于迟到请求回包，pending 快照不依赖是否新增了历史气泡。
- 发送快照与新草稿分开，HTTP 在途与等待回复分开；输入法确认不能误触发送。
- 共享频率预算在成功提交后消耗，进行中占位与已成功不能混为一谈。
- 富文本选区统一坐标；分页同时考虑宽高，长内容保留可达的滚动路径；删布局容器时核对其中的操作和事件提示。
- 桌宠模式需同时检查原生窗口几何、拖动、焦点与完整端入口，CSS 隐藏不等于窗口切换。

## 存储、部署与验证

- SQLite 与 PostgreSQL 的参数、事务、标量函数、分页和 checkpoint 结构有差异，必须经过真实存储路径验证。
- 迁移支持的源版本、外键顺序、时间精度、旧缺表和资源路径一起检查；默认数据位置不能无兼容方案切换。
- 启动就绪要验证本次自有进程身份；端口可连不代表启动正确，未知占用不能强杀。
- 打包后单独 smoke；开发源码通过不能证明冻结依赖、release 分支和退出回收正确。本地拆包要同步各安装入口。
- Railway 私网上游、代理 Host 与公网 origin 分别核对；卷权限、日志和实际 API/SSE 都要验证。
- 二进制备份经过 CLI/PowerShell 时注意字节改写；按既有流程传输后校验摘要并在隔离环境真实恢复。
- 测试环境隔离认证、数据库与外发配置；替身保持真实异步接口。模拟管道通过不代表模型效果、真实数据库或真实页面通过。
- 子进程场景通过不代表覆盖已采集，要核对本次合并数据；pytest 空参数集合会跳过并返回成功，完整验收入口应显式拒绝空驱动集合。
- E2E 的 HTTP 监听就绪不代表后台消费者启动完成；就绪屏障需等待实际 worker，并立即暴露启动任务异常。采集开销下的驱动限时与独立入口对齐，但保留失败与有限超时。
- 测消费行为和用户路径，不复制声明或实现；最终回复依据实际执行证据，未运行的验收明确标出。
- 删除工程入口前查独立消费者；移动或删除文档后，从新位置检查内部链接、引用方和已删除文件引用。
