# 陪伴读书（合并 nyx_read_companion）设计文档

> 状态：**已收敛** —— 功能边界与关键决策点均已拍板（见 §5），落地时据此拆 spec。
> 参考项目：`nyx_read_companion`（独立「书友 App」）。本功能把其核心合并进 V1，**不照搬其独立架构**。

## 1. 定位与目标

Nyx 在用户读书时**同步陪读**——用户翻页、Nyx 逐段追赶、读到精彩处碎碎念/提问、偶发记忆联想、章末整理笔记、给用户笔记批注。

一句话：从「Nyx 自己躲房间看书」（现有读书活动）升级为「你读书时她凑过来一起读，在旁边嘀咕」。

## 2. 用户旅程（V1 形态）

```
1. 前端底部导航栏「读书」入口 → 打开书架面板（已导入书 + 进度）
2. 点「导入」→ 选 EPUB 文件 → 解析成段落入库
3. 点一本书 → 阅读页（左：正文段落；右：Nyx 侧边栏）
4. 用户翻页 → Nyx 按自己速度逐段追赶（侧栏显示她读到第几段）
5. 翻页 → 冲动引擎评估该段 → 触发碎碎念 / 提问 / 记忆联想气泡
6. 用户选中文本记笔记；或直接在对话框和 Nyx 讨论书中内容
7. Nyx 的碎碎念/提问自动汇入她的笔记 buffer
8. Nyx 读到章末 → 后台整合她的 buffer → 章末笔记
9. 用户点「给尼克斯看」→ 她批注用户笔记
10. 下次打开同一本书 → 恢复进度 +「上次我们读到…」
```

## 3. 功能边界

### 3.1 做什么（核心闭环）

| # | 功能 | 说明 | 对应参考 spec |
|---|---|---|---|
| 1 | EPUB 导入 | 解析 EPUB → 段落（`paragraphs` 表）+ 元信息（`books`：标题/作者） | S03 |
| 2 | 书架 | 已导入书列表 + 阅读进度展示 | S04 |
| 3 | 同步阅读 | 分页阅读 UI + 用户翻页 + Nyx 按速度逐段追赶 + 进度持久化 | S05 |
| 4 | 冲动引擎 | 段落特征提取 → 6 维驱动 → 加权复合 → 触发碎碎念/提问/联想 | S06 |
| 5 | 碎碎念（翻页触发） | 复用 V1 mutter 骨架，注入段落内容 | S09 |
| 6 | 冲动提问 | 提问气泡（知识型/个人型/反思型/划线提问） | S10 |
| 7 | 记忆联想 | 读到某段 → 检索 V1 记忆 → 联想气泡 | S06/S07 |
| 8 | 双缓冲笔记 | 用户笔记 + Nyx 笔记自动记录（碎碎念/提问 source 标记） | S08 |
| 9 | 章末整合 | Nyx 读完一章 → LLM 整合她的 buffer → 章末笔记 | S08 |
| 10 | 展示批注 | 用户点「给尼克斯看」→ Nyx 批注用户笔记 | S08 |

### 3.2 不做什么（明确排除）

| 功能 | 排除理由 |
|---|---|
| 开发者模式（调试仪表盘 + 参数热调 UI） | 作品集定位不需要；V1 前端已有基础面板 |
| 场景化 Eval（S14） | V1 已有 pytest + mock LLM 测试体系 |
| 完整认知演变（S12 行为级参数漂移） | 复用 V1 内在生命（性格/三观/审美漂移），不另做一套 |
| 用户笔记自动合并进 Nyx 笔记 | 参考项目明确「严格分离」，保持 |
| 独立 IPC / Tauri 层（S00） | 复用 V1 已有 SSE over localhost |
| 多用户/账号、云同步、手机/Web、TTS 朗读 | 参考项目已排除，V1 同样排除 |

## 4. 与 V1 已有系统的关系

| V1 已有 | 处置 | 说明 |
|---|---|---|
| 记忆系统（含联想 networkx） | **复用** | 联想气泡直接检索 V1 memory，不新建；阅读记忆落 V1 memory（`tag="reading"`） |
| 表达系统（mutter/搭话/回复） | **复用 + 加入口** | mutter 骨架复用；加「翻页触发」入口 |
| 欲望系统 | **并存** | 管「要不要读书」；冲动引擎管「读到这段的反应」，不同层次 |
| 内在生命 | **复用 + 加审美维度** | 性格/三观漂移复用；新增审美 4 轴（§6），和性格同循环偏移 |
| 活动系统（读书活动/material 表） | **分开** | `material`（Nyx 自己读的分块文本）与 `books`（用户读的章节段落）结构不同，两表各管各的 |
| 事件总线 + SSE | **复用** | 冲动的碎碎念/提问/联想走现有事件广播 |
| 观察系统 | **不用于陪读** | 陪读是「用户主动在阅读页翻页」，不靠窗口观察猜测 |

## 5. 已定决策（收敛结论）

### 5.1 EPUB 先行，网页 URL 之后做

- **先做 EPUB**（范围最小，聚焦电子书，参考项目 S03）。
- 网页 URL 也做成「可阅读的书」**之后排期**（复用 `web_fetch`），本期不做。

### 5.2 冲动引擎 6 维驱动 → 并存 + 映射 + 审美维度

S06 六维驱动是「读到这段的即时反应」（快变量），与 V1 欲望（要不要读书）、内在生命（慢变量）**并存**。逐维处置：

| 驱动 | 语义 | 基线·衰减(/s) | V1 处置 |
|---|---|---|---|
| motivation 动力 | 阅读活跃度 | 0.5 · −0.001 | **映射** → 精力 |
| curiosity 好奇 | 提问欲 | 0.6 · −0.003 | **映射** → 探索欲 |
| boredom 无聊 | 重复耐受度 | 0.3 · −0.001 | **映射** → 互动欲 |
| associative_drive 记忆联想 | 联想度 | 0.4 · −0.003 | **映射** → 记忆联想 |
| aesthetic_sensitivity 审美敏感 | 对文风敏感度 | 0.5 · −0.002 | **临时**，阈值靠新增审美维度（§6） |
| empathy_bias 共鸣倾向 | 对人物共鸣 | 0.6 · −0.002 | **临时**，阈值靠宜人性/三观 |

- **4 驱动映射** V1 已有状态（动力→精力、好奇→探索欲、无聊→互动欲、联想→记忆联想）。
- **2 驱动临时**（审美敏感、共鸣倾向），阈值靠感性/三观定：审美敏感 → 新增审美维度；共鸣倾向 → 宜人性。
- 冲动引擎的「特征→复合→触发」公式照搬参考项目 S06，驱动状态用上述映射/临时状态表示，不另起一套状态模型。

### 5.3 记忆生成时机（4 个，不做「每段」）

阅读也会生成记忆，落 V1 memory 表（`tag="reading"`）。**四个时机**（不做「每段」）：

1. **章末整合**——Nyx 读完一章，整合她的 buffer → 章末记忆。
2. **读完整本**——读完全书，1 次整合 → 全书记忆。
3. **对话讨论**——阅读页对话框里和 Nyx 讨论，产生对话记忆。
4. **联想触发**——记忆联想气泡被确认/采纳时，落联想记忆。

**不做**：中途切到聊天界面的「阅读上下文快照」注入（用户判断：阅读页已有讨论窗口，没人会在读书时切去聊天）。

### 5.4 Nyx 追赶定时器：前端 setTimeout，秒级逐段

- **前端** `setTimeout` 按 `reading_speed` 推进 `nyx_position`（照搬参考项目 S05 的 readerStore 结构）。
- 逐段追赶是**秒级**（不是分钟级），进度 UI 即时响应。
- 后端不另起 tick 推进翻页到 Nyx 的追赶。

### 5.5 书架入口：底部导航栏 + material/books 分开

- 前端**底部导航栏**（聊天旁边）加「读书」入口 → 点开书架 → 选书和 Nyx 一起读。
- `material`（Nyx 自己读的分块文本）与 `books`（用户读的章节段落）**分开两表**：结构不同，各管各的，不统一成「内容库」。

### 5.6 分期：P1 / P2 / P3

| 期 | 内容 | 依赖 |
|---|---|---|
| P1 内容层 | EPUB 导入 + `books`/`paragraphs` 表 + 书架 + 阅读页 + 同步进度 | 无 |
| P2 行为层 | 冲动引擎（特征→驱动→复合→触发）+ 翻页碎碎念/提问 + 记忆联想 | P1 |
| P3 笔记层 | 双缓冲笔记 + 章末整合 + 展示批注 | P1 |

> P1 跑通即可演示「同步陪读」；P2 是行为灵魂；P3 收尾笔记闭环。

## 6. 审美维度（内在生命新增）

> 从参考项目 S06「审美偏好」升级而来：参考项目只是冲动引擎里的 4 个偏好参数，这里**升级成内在生命维度**，和性格/三观一起慢漂移。

### 6.1 四轴与标度

- 4 轴（1-10，**5 = 中性，10 = 第一极**）：
  - 华丽 ↔ 简洁
  - 抒情 ↔ 冷峻
  - 古典 ↔ 现代
  - 沉重 ↔ 轻盈

### 6.2 初值（由参考项目 0-1 标度换算）

换算公式：`1-10 分 = round(参考值 × 9 + 1)`（参考值 > 0.5 = 偏第一极）。

| 轴 | 参考值 | 初值 |
|---|---|---|
| 华丽 ↔ 简洁 | 0.65 | **7**（偏华丽） |
| 抒情 ↔ 冷峻 | 0.70 | **7**（偏抒情） |
| 古典 ↔ 现代 | 0.60 | **6**（偏古典） |
| 沉重 ↔ 轻盈 | 0.55 | **6**（偏沉重） |

### 6.3 偏移机制（和性格同循环，阅读量缩放）

- 审美和性格/三观在**同一个反思循环**里偏移：反思 LLM 输出 `aesthetic_delta`，`drift_aesthetic` 复用 `_drift_dim`（clamp ±0.5 → [1,10]）。
- **阅读量门控**：审美偏移量 × 阅读量缩放，比性格更慢（性格有「新记忆」就满额漂，审美要「读够章」才满额）：

```
最终 aesthetic_delta = aesthetic_delta × min(新读章数 / 3, 1.0)
```

| 距上次反思新读章数 | 缩放因子 | 审美偏移 |
|---|---|---|
| 0（没读书） | 0 | 不动 |
| 1~2 章 | 1/3 ~ 2/3 | 按比例缩 |
| ≥ 3 章 | 1.0 | 满额 ±0.5 |

- **信号**：新读章数 = 距上次反思新增 `tag="reading"` 记忆条数（一条 ≈ 一章，章末整合生成）。
- **阈值常量**：`_AESTHETIC_MIN_READING = 3`，模块级（同反思参数，不进 config）。
- **落点**：新 `aesthetic` 单行表（`id='self'`，4 列），不并入 Big Five（保 5 维完整）也不并入三观（语义不符）。
