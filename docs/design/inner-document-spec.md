# 动态内在文档重构 Spec

状态：已实现，当前规则以正文及 2026-11-10 全局清理结果为准；较早验证记录仅描述当时版本。用户已授权先写 spec 后实施；范围为长期内在状态的统一、局部修订及其全部消费者。

## 目标与边界

人格、世界观（三观）、审美、关系、动机、自我理解与个人叙事只维护一份当前文档。删除 Big Five、三观、审美数值及其漂移、行为映射和界面量表。情绪、精力、欲望压力等运行数值继续服务调度，不从文档反推人格分数。

静态角色资料负责小说原型、能力与资料边界；动态文档负责现在的我。初始化给出安静、敏感、谨慎靠近、愿意理解也希望被理解的起点，后续实际经历可以改变它。关系表述是角色自身的理解，不能凭空确立用户的感受或承诺。

## 文档与锚点

每个角色在数据库内保存一个文档，使用有顺序的主题条目组织，渲染为 Markdown。条目包括稳定的主题 ID、所属部分、标题和正文。部分包括自我理解、世界观、关系、动机、人格、审美、个人叙事和尚未想明白的事。标题可以变化，主题 ID 不因改名变化；例如 `worldview / view-of-humans` 定位世界观中的“对人类的看法”。不得维护另一份平行的 story/self_view/becoming 状态。

文档有版本号和最近反思时间；内容有总长度和单条长度限制，避免无限追加。历史变化在反思记录中保存，不在当前正文中无限累积。

## 反思协议

修改内在状态的反思读取完整当前文档、近期有效事实、记忆、对话、长期欲望和待消化阅读原文。反思输出摘要、主题修订和可选长期欲望候选。允许零修订，不要求每次产生新成长。

修订按部分和主题 ID 定位，支持设置（新增或替换该主题正文）及删除。每项变更给出理由和来源证据，世界观、审美与其他主题使用同一规则，不按部分设立独立更新条件。未知部分、重复目标、目标不匹配、无效删除、空正文、超长正文及无依据修改整体拒绝，不使用模糊文本替换。新的主题必须位于已有部分下，ID 不得与其他主题冲突。

审美不再单独生成数值；在同一轮反思中修改审美主题。阅读证据只在成功提交后消费。没有引发变化的有效阅读材料也可以明确消化，不能因无修改反复提交。

模型调用在事务外准备；提交时校验基础版本与最近反思时间，在同一事务写入文档、接受的欲望、证据消费和反思记录。版本冲突重新准备；重复投递不重复应用；失败回滚全部核心结果。空修订更新最近反思时间，正文版本不变。

## 消费者

聊天快慢通道、主动搭话、碎碎念和创作读取同一文档。静态提示词不以固定人格覆盖文档。阅读冲动依据文本、精力、欲望及现有冷却决定触发，删除宜人性与审美敏感度分数，实际表达参考文档。删除长期欲望对旧三观数值键的关联字段。内在文档统一为 `InnerDocument` 与文档读写接口，回复 checkpoint 不另存叙事副本。

API 提供文档及运行状态，SSE 完成事件使用 `summary` / `document_changed` 表示本轮摘要与文档是否变化，通知前端刷新文档、欲望和反思记录；内部反思摘要不自动生成对话或气泡。前端内在状态页展示主题文档，删除三类数值图表。角色创建、导入、导出只接受 v2 文档格式，删除 v1 数值卡转换。角色切换、重启和卸载恢复不得重新覆盖已有文档。

## 迁移

数据库迁移只把旧身份、自画像、故事和认知变化等已有文字搬入主题文档，删除旧数值到文字的倾向映射，不再读取或推断旧人格、三观和审美分数。按用户要求移除旧数值；旧表在成功迁移后删除，历史反思记录不改写，已存在的当前文档不重新初始化。历史建表与删表 DDL 仅用于数据库版本升级。SQLite 与 PostgreSQL 使用同一迁移语义，迁移原子提交；失败保留原状态，重试不重复追加。超出当前文档容量的旧文字存档拒绝迁移，保留原数据供整理，绝不截断或静默丢弃文字。

## 实施顺序与验证

1. 文档模型、锚定修订与迁移；角色卡及初始化。
2. 内在反思准备/提交、读取与事件；更新全部后端消费者和协议。
3. 前端文档展示和角色创建；清理量表、旧类型与失效分数测试，更新相关 facts 和操作入口。
4. 运行相关既有回归和静态检查、前端构建；验证迁移、局部修订、零修改、无效补丁、证据、并发冲突、失败回滚、重放、重启与多角色隔离。仅为关键修订/迁移回归补必要测试。
5. 在临时隔离数据中用真实模型验证：初始聊天语气、依据对话修改关系主题、依据阅读修改审美主题，以及修改后聊天/创作的实际表现。分别报告真实与模拟验证；不操作线上数据，不以历史通过记录代替本次验证。

## 本次实施与验证结果（2026-11-09）

- 已删除运行时人格、三观、审美数值及量表，主题文档成为唯一当前内在状态。情绪、精力、欲望压力继续作为运行数值；行为技能反思仍更新技能与行为经验，不改人格。
- SQLite 迁移、精确主题修订、无变化、非法引用、审美证据、事务回滚与重试、重复提交、重启与角色隔离回归通过；关键回归 176 项通过，API 与角色相关最终路径 154 项通过。
- 全量隔离回归曾有 1482 项通过、1 项跳过，剩余旧 API 字段断言及对话恢复 E2E 超时。旧断言已更新且定向通过；对话恢复 E2E 单独重跑全部场景通过。没有把修复前的全量运行记为全量通过。
- 临时 PostgreSQL 16 实库通过旧 schema 54 到 55 迁移、新库与官方 saver 初始化、微秒时间戳保存，以及两个连接的空修订竞争：后提交者等待并拒绝过期快照。临时容器已清理。
- Ruff、Pyright 和前端构建通过；前端 411 项测试通过。实际页面导航在当前 headless Edge 环境超时，页面视觉验收未完成，不能把组件测试当作页面验收。
- 真实 deepseek-chat 在临时 SQLite 中根据合成对话修改既有关系主题、根据合成小说原文修改审美主题；原句引用校验、文档版本增加、阅读证据消费和后续创作通过。反思只调用同一套协议，没有独立审美数值调用。
- 语气为有限样本评估：谈论小说人物的延续时能表达迟疑与被触动；日常报平安仍出现“吃饭要紧”等照料式惯用表达。初始文档已强化自身感受和小心靠近，但不能认定所有场景的语气已经稳定达到示例。一次真实模型补测连接失败，后续重试成功；未操作线上数据或发送 QQ。

## 全局清理与验证（2026-11-10）

- 扫描 305 个后端、前端、桌面壳、测试、脚本与配置文件，并沿初始化、反思写入、聊天快慢通道、主动表达、阅读互动、创作、API 和前端状态读取核对。运行数据、依赖与生成图谱不作为业务源码。
- 补删上一轮漏掉的旧分数转文字规则与阅读审美敏感度驱动；反思型提问使用其余文本共鸣及好奇心权重归一化。段落丰富度仅服务阅读碎碎念触发，不代表角色审美或人格。
- 世界观、审美和其他主题使用相同证据及局部修订规则，取消仅允许阅读原文修改审美的分支。真实模型首次将对话 ID 误填入阅读消费数组，校验拒绝提交；提示词明确区分阅读与其他来源后复测通过，校验未放宽。
- 文档模型和存储接口统一为 `InnerDocument`、`get_document` / `upsert_document`；删除回复 checkpoint 中多余的叙事副本及未使用的 `/api/narrative` 接口。前端从当前状态快照读取文档；业务写入仅来自初始化与内在反思。创作风格依据当前文档，不由固定原型风格覆盖。
- 数值计算、维度映射、旧角色卡兼容与图表均无运行时残留。旧字段名仅存在于数据库历史建表、删表语句及迁移断言；升级只搬运已有文字并删除旧数值表，已存在的当前文档不重置。
- 最终隔离配置下全量后端回归（含现有 E2E）1496 项通过、1 项跳过；前端 411 项通过，构建、Ruff、Pyright 通过。首轮直跑曾受本机认证配置影响，并发现两处新测试参数遗漏和阅读排序样本失效；修正后运行上述全量回归，不以首轮结果宣称通过。
- 临时 PostgreSQL 16 实库通过新库初始化、54→55 升级、微秒时间保存、旧文字保留、旧表删除与幂等重试；临时容器已删除。真实 deepseek-chat 在临时 SQLite 中仅依据一份合成对话，局部修改既有世界观和审美主题，引用逐字校验、版本增长及无关主题保留均通过；这是有限样本，不代表所有场景的语气质量。本轮未做浏览器视觉验收，未操作用户运行数据或线上数据。
