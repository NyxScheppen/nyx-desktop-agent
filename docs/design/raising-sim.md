# 养成游戏改造（文字冒险 / 养成 / 书卷风）

> 把 Nyx 从「仪表盘 / 抽屉」形态改造成「养成游戏」形态：书卷风三区布局 + 新增「遭遇」子系统 + 交互性（选择支 / 遭遇抉择）+ 显式呈现「她在成长」。
> 本文档记录**设计决策**；实现细节进 spec（后端 `19-encounter.md`、前端 `06-game-shell.md`）。

## 1. 定位与拆分

三块 + 一块推迟：

- **A. 前端重构（书卷风 Galgame 壳）** — 现有面板堆 → 三区极简布局；中世纪奇幻书卷风，摒弃现有粉渐变 / 樱花。
- **B. 遭遇系统（新后端子系统）** — 活动日程块上的随机叙事节拍，带选项、带后果。
- **C. 陪读（推迟）** — 和用户一起读书，参考 `D:\Desktop\nyx_read_companion`，本轮不做。

A 与 B 耦合：B 的遭遇（`ENCOUNTER_START` 事件 + 选项）渲染在 A 的「书卷区」。

## 2. 交互性（核心循环）

用户要的交互性 = 选择支 + 遭遇抉择（不做硬等级）：

1. **选择支**：书卷区的可点选项直接决定她下一步（文字冒险分支感）。
2. **遭遇抉择**：遭遇里做选择，后果改属性 / 记忆。

「她在成长」落地见 §4。

## 3. 遭遇系统（B）

### 3.1 定位

遭遇 = 活动日程块生命周期上的**随机叙事节拍**，roguelike 味。它不是第七种活动（不消费欲望、不产普通活动结果），而是一个横切在活动 / 表达 / 内在生命之上的新子系统，复用：事件总线 + 表达 LLM 管线 + 内在生命 / 欲望 / 记忆的状态回写。

### 3.2 触发点（从日程块切入）

| # | 触发点 | 时机 | 说明 |
|---|---|---|---|
| 1 | 欲望搭话 | 空闲时互动欲攒够 | 重分类现有 `initiate_chat`（遭遇类型一） |
| 2 | 块边界遭遇 | `SCHEDULE_BLOCK_START` → `_maybe_start_activity` 启动活动后掷骰 | 新增，MVP 主入口 |
| 3 | 活动中遭遇 | `_run_activity` 自然暂停点掷骰 | 新增（plan 排最后） |

掷骰 = 纯函数（概率 + 冷却 + 精力 + 在线不忙），可单测，同 `should_initiate_chat` 风格。

### 3.3 包装 vs 抢占

- 默认**包装**：遭遇叠加在活动上，活动照跑，不破坏欲望排期。
- **成长时刻**（里程碑）可**抢占**：独占这一块。

### 3.4 遭遇类型（首版 3 类）

1. **欲望搭话**：互动欲主动开场（重分类现有机制）。
2. **随机事件**：环境 / 意外（读书读到一半停电、搜索发现奇怪论坛）。
3. **成长时刻**：里程碑（读完第一本书、第一次探索、性格 / 三观明显漂移）。

### 3.5 生命周期与事件契约

```
ENCOUNTER_START ──> 前端书卷区渲染 [文本 + 可点选项]
      │ 用户点选项
POST /api/encounter/choose ──> ENCOUNTER_CHOICE
      │ 应用后果
ENCOUNTER_END [结局叙事 + 后果]
      │ 回写
ROUTING[ENCOUNTER_END] = ["inner_life", "desire", "memory"]
```

- 生成：1 次 LLM（复用 expression 拼 system prompt 风格，注入「当前活动 + 情绪 + 欲望 + 自我叙事」），产 `{text, options[2-4]}`，每选项带后果。
- 后果纯函数：每选项 `{energy_delta, emotion_shift, desire_value_add, memory}`，不额外调 LLM 判后果（design §7.4 同款原则）。
- 事件：`ENCOUNTER_START / CHOICE / END` 三个新 EventType，SSE 全量推。
- 持久化：MVP 走 event_log + memory（成长时刻 / 重要遭遇落场景记忆），不新建 encounter 表。

## 4. 「她在成长」落地（里程碑 + 叙事可见）

不引入硬等级。成长 = 慢变量漂移 + 里程碑显式化：

- 遭遇 → **快变量**（情感 / 精力 / 欲望值），左面板属性立刻可见地动。
- 成长时刻 / 重要遭遇 → **场景记忆** → **反思** → **慢变量**（性格 / 三观 / 自我叙事漂移）。
- **前端显式呈现**：左面板属性 + 自我叙事「最近的变化」+ 成长时刻遭遇，让「她走过的路」被讲出来。

## 5. 前端重构（A）

### 5.1 三区布局

```
+------------------+----------------------------------------+
|  左侧面板 (30%)   |  右侧主区域 (70%)                       |
|  心情/精力（展示） |  +------------------------------------+ |
|  她现在的念头     |  |  书卷区域（对话主舞台）            | |
|  空间（入口）     |  |  文字 + 可点选项                   | |
|  正在做什么       |  +------------------------------------+ |
|  游戏设置         |  +------------------------------------+ |
|  [大头照]         |  |  Galgame 对话框（输入 + 发送）     | |
|  姓名             |  +------------------------------------+ |
+------------------+----------------------------------------+
```

### 5.2 现有面板去向（她视角 vs 开发者视角）

| 现有内容 | 新壳去向 |
|---|---|
| 聊天 / 遭遇 / 成长时刻 | 书卷区对话主舞台（默认，时间线滚动） |
| 精力 / 情绪 / 性格 / 三观 | 左面板「心情」纯展示 + 「她现在的念头」点开内在详情 + 成长变化高亮 |
| 欲望 | 左面板「她现在的念头」一句话 + 点开队列 |
| 读书笔记 / 产出 / 资料 | 左面板「空间」点开空间详情 |
| 活动 / 记忆 | 左面板「正在做什么」一条 + 点开记录详情 |
| 材料 / 上传 | 左面板「空间」入口（资料面板） |
| eval + token 看板 | **摘出**：独立调试页（快捷键 / 隐藏入口），游戏 UI 极简 |

### 5.3 风格：中世纪奇幻书卷风

- 摒弃现有「粉渐变 + 樱花 + 现代玻璃面板」。
- 换：羊皮纸质感、衬线字体、中世纪装饰边框、暖色调。
- 立绘 / 表情：**沿用现有 8 档 sprite**（不重绘）。
- 色板 / 字体：默认羊皮纸暖棕 + 衬线字（实现者定，进前端 spec）。

### 5.4 交互性

- 遭遇可点选项（选择支 + 遭遇抉择）。
- 左面板属性随遭遇 / 活动实时变化（成长可见）。
- 内心世界入口收敛到左面板三摘要按钮（内在 / 空间 / 记录），书卷区专注对话。

## 6. 明确不做 / 推迟

- **陪读**（C）：和用户一起读书，参考 `nyx_read_companion`，推迟。
- **硬等级 / 羁绊数值**：不做（成长走里程碑 + 叙事）。
- **语音**：保持现有 TTS，不因本改造变化。
- **电脑控制 / computer use**：不在本改造范围。

## 7. 待定 / 开放项

- 块边界 / 活动中的遭遇触发概率 / 冷却默认值（进 spec 时定）。
- 遭遇是否新建持久化表（MVP 倾向不建，走 event_log + memory）。
