# 角色卡与宿主基本事实

> 记录职责与关键边界；卡片字段、校验、额度和生命周期细节查源码。

## 职责与行为

- 原生角色卡由 YAML、Markdown 和可选图片组成，内置 Nyx 卡在 `nyx/cards/nyx/`；导入和操作见 [本地操作](../operations.md#角色卡)。
- 宿主管理角色注册、启动、切换、卸载与恢复；切换不会重建角色，卸载保留存档供恢复。
- 各角色独立保存记忆、欲望、内在生命、活动、阅读、表达历史和工作区；模型资源与桌面观察能力可共享。
- 初始人格和欲望只初始化一次，重启、恢复或切换不会覆盖成长。
- 本地使用宿主与角色 SQLite；托管时使用 PostgreSQL 中分离的宿主和角色 schema，卡片与工作区仍需文件持久化。
- API 写入固定其角色运行时，前端请求也绑定角色范围；迟到响应不能污染切换后的角色。
- OneBot 按配置绑定角色，与桌面当前选择独立。主动行为还受角色运行状态、presence、精力与冷却等条件约束。
- 启用根凭证后支持一次性设备配对与独立设备令牌；只有根凭证管理设备，仍是单用户模式。
- 角色关闭需等后台写入停止；超时保留可恢复状态，不能直接关闭仍在使用的数据库。

## 源码入口

- `nyx/character_cards.py`、`nyx/cards/nyx/`：卡包与内置内容；`nyx/bootstrap.py`：初始化。
- `nyx/app_context.py`、`nyx/runtime.py`：宿主和角色生命周期。
- `nyx/api/routes.py`：角色操作、认证与设备配对。
- `frontend/src/api/characterScope.ts`、`frontend/src/stores/characterStore.ts`：前端归属与切换。
