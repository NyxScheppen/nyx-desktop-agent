# 欲望系统基本事实

> 记录职责与关键边界；公式、阈值、字段和状态转换查源码。

## 职责与行为

- 管理互动、探索、创造和休息四类压力，以及短期、长期欲望。
- 压力受经历、活动、精力与长期欲望影响，随时间变化；达到准入条件后才生成短期欲望。
- 长期欲望提供行动方向和主题，强度影响驱动力；运行时新增长期欲望来自反思。
- 活动与主动搭话消费短期欲望，必须先领取，不能依赖先读再写来防重复消费。
- 完成、部分进展、打断和失败分别处理；一次活动有进展不一定意味着欲望已经满足。
- 欲望与来源活动的关联会持久保存，完成后据此结算，不靠相似描述猜测归属。
- 周期结算、生成结果和消费结果具有重放保护；提交后的唤醒失败不撤销已提交状态。
- 角色卡的初始压力和长期欲望只初始化一次，恢复角色不会覆盖成长或重新填满已清空的欲望。

## 源码入口

- `nyx/desire/facade.py`：事件入口、状态查询、领取与长期欲望入口。
- `nyx/desire/lifecycle.py`、`value.py`：压力、生成与生命周期。
- `nyx/desire/store.py`：存储与原子状态操作；`nyx/bootstrap.py`：角色初始化。
- `nyx/activity/`、`nyx/expression/`：欲望的主要消费者。
