# 内在生命系统基本事实

> 记录职责与关键边界；数值规则、字段和提交步骤查源码。

## 职责与行为

- 管理情感、精力和一份动态内在文档；文档承载自我理解、世界观、关系、动机、人格、审美、个人叙事及疑问。人格、三观与审美不再存为数值。
- 情感是进程内状态，重启回到中性；精力与内在文档会持久化，欲望压力仍由欲望系统管理。
- 情感与精力按经过时间结算，读取当前状态也可能触发惰性恢复或衰减。
- 最终展示情绪同时受情感、精力和当前活动影响，不能只由某一个数值推断。
- 当前状态是多个系统读取结果的组合，不是所有表同一时刻的事务快照。
- 修改内在状态的反思是运行时修订文档和提出长期欲望的入口；聊天、活动与行为技能反思不直接改写人格。
- 反思依据近期记忆、原始对话、有效事实及阅读原文，按部分与稳定主题 ID 局部设置或删除；世界观、审美和其他主题使用相同的理由及原句引用规则，也允许无修改。
- 文档版本校验、阅读证据消费、欲望和完整反思记录原子提交；失败回滚，冲突重新准备。空修订更新反思时间，正文版本不变。
- 反思完成事件携带摘要和文档变化标志，前端刷新文档、欲望和记录；内部反思摘要不自动生成气泡或聊天。
- 聊天快慢通道、主动表达、阅读互动与创作读取同一份文档；静态资料负责小说原型与能力边界，不覆盖人格成长。
- 旧存档只搬运已有文字，成功后删除旧表和数值；不再把人格、三观或审美分数解释成文字倾向。超出文档容量或损坏的文字数据会拒绝迁移并保留原存档。
- 周期、记忆矛盾、批注纠错、重读及空闲活动可请求反思；过期请求与重复投递不会重复施加成长。
- 初始化使用角色卡；恢复已有角色不覆盖成长。模型准备与本地状态提交分开，核心失败由持久投递恢复。

## 源码入口

- `nyx/inner_life/facade.py`：当前状态、情感与精力、事件消费。
- `nyx/inner_life/reflection.py`：反思；`document.py`：主题校验与修订；`emotion.py`：情绪计算；`store.py`：持久化。
- `nyx/bootstrap.py`、`nyx/plugins.py`：初始化与依赖接线。
