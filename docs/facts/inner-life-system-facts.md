# 内在生命系统基本事实

> 记录职责与关键边界；数值规则、字段和提交步骤查源码。

## 职责与行为

- 管理情感、精力、Big Five 性格、三观、审美及自我叙事。
- 情感是进程内状态，重启回到中性；精力、慢变量与自我叙事会持久化。
- 情感与精力按经过时间结算，读取当前状态也可能触发惰性恢复或衰减。
- 最终展示情绪同时受情感、精力和当前活动影响，不能只由某一个数值推断。
- 当前状态是多个系统读取结果的组合，不是所有表同一时刻的事务快照。
- 反思是运行时改变慢变量和提出长期欲望的入口；普通用户消息、批注或活动不会直接任意重写人格。
- 反思依据近期记忆、有效事实、现有叙事和长期欲望形成变化；更新有幅度约束，核心身份不随普通反思替换。
- 周期、记忆矛盾、批注纠错、重读及空闲活动可请求反思；过期请求与重复投递不会重复施加成长。
- 初始化使用角色卡；恢复已有角色不覆盖成长。模型准备与本地状态提交分开，核心失败由持久投递恢复。

## 源码入口

- `nyx/inner_life/facade.py`：当前状态、情感与精力、事件消费。
- `nyx/inner_life/reflection.py`：反思；`emotion.py`：数值计算；`store.py`：持久化。
- `nyx/bootstrap.py`、`nyx/plugins.py`：初始化与依赖接线。
