# 记忆系统基本事实

> 记录职责与关键边界；具体算法、字段和生命周期查源码。

## 职责与行为

- 同时管理对话原文段、整理后的事实、外部资料证据、传统记忆及失败经验；这些数据的来源和用途不同。
- 对话按实际回合归档，原文保留；摘要、主题和向量是辅助索引。终局重放只补缺少的归档，不重新生成回复。
- 新对话同时维护带原文位置的分块、全文倒排和向量索引；召回经过 BM25/向量多路融合、相关性重排和相邻原文补全。日常优先活跃段，明确追忆与 `memory_recall` 可检索冷归档；旧归档未回填时沿用兼容检索。返回片段不改写归档原文，来源段、块和字符范围可追溯。
- 普通回复可召回用户事实与相关对话段；外部书籍和网页知识走专门的知识检索，不混作用户亲身经历。
- 检索结合语义与关键词；联想使用记忆关系。只有实际进入回复上下文的记忆才算召回使用，检索命中本身不计。
- 写入会去重，来源、否定、数字与时间差异会影响能否合并；创建时间、发生时间和新鲜度更新时间不能混用。
- 书籍、网页等资料保留来源和证据，文学第一人称不归到用户或 Nyx 身上。事实抽取也不能把提问、引用或讨论内容直接当成用户事实。
- 用户对回复的批注独立持久记录；明确纠错可积累为经验并触发反思。超时未回答不会自动生成用户记忆。
- 研究结果、工具失败、角色偏离与达到阈值的用户纠正进入独立行为反思；经验先持久化，之后才允许模型修改对应 skill 的策略正文。保留原始证据、反思原文、入库全文、版本差异和提交时间；不改变内在状态。
- 行为经验按已持久化反思中的 skill 归属召回，归属不明的不混入策略上下文；有用户纠正原文的经验（包括用户纠正 OOC）可进入内在反思证据和触发计数，自动 OOC 告警及研究策略经验不进入。角色偏离只作为待核实信号，行为反思参照执行时固定的角色设定和内在文档，不再使用固定 Nyx 语料给所有角色评分。
- 自由探索与对话研究共用可组合的研究图和 discussion skill，普通对话使用 conversation skill。先审查资料，再消化和提交知识；抓取失败立即终止。暂停恢复使用原执行快照和知识回执，skill 新版从下一次执行生效。
- 内在反思与状态变化同事务保存完整记录，包括触发依据、对话原文、模型输入输出及变化前后状态；记录不转成外部事实，也不计入下一轮反思积累。
- 记忆页可按类型筛选并展开对话原文；浏览包含已退出召回的历史段，浏览结果不代表回复时全部被召回。知识事实网支持拖动节点、平移和缩放。
- 数据、索引及归档归属各自角色；失败和重放需同时检查原文、派生索引与消费者结果。
- 历史活跃段与冷归档由角色记忆维护循环逐批回填；任务、原文修订和已完成分块持久化，重启可续跑，嵌入失败退避重试。嵌入在数据库事务外执行，提交前校验来源修订；修改、删除或请求重建后，旧任务不能写回。
- 对话向量按编码器制品指纹隔离；相同维度不代表兼容。模型或切块版本变化后自动补建，旧制品在进程启动时确定，更换制品需重启角色。重建期间保留原文和关键词召回，不比较未知版本的旧父段向量。
- 追加回合保留旧证据和事实时序；替换原文撤回该来源事实并等待重新评估，删除原文同时清理分块、任务、来源事实与相关检索追踪。时间事实仍按发生时间的有效区间查询，迟到的历史事实不能覆盖后续状态；撤回来源不会擅自复活先前已过期的状态。
- 对话分块检索保存候选分数、来源位置、选中结果及实际注入回复上下文的事件 ID；注入不等于模型确实采用。追踪不复制查询或对话正文，保留最近 7 天且最多 2000 次；变更日志可压缩，落后的常驻索引重新载入。回填前旧段的兼容召回不提供分块追踪。

## RAG 运维入口

以下路径位于角色 API `/api/characters/{character_id}` 下，沿用现有认证和角色隔离。维护循环随运行中的角色启动，每轮限定处理量；`ready` 表示该版本索引构建完成，不代表召回质量评测通过。

| 方法和路径 | 用途 |
| --- | --- |
| `GET /memories/rag/status` | 查看目标版本、完成/待处理/失败数量及近期任务的重试时间 |
| `POST /memories/rag/rebuild` | 使旧任务失效并排队重建，返回 202；下次维护逐批执行 |
| `GET /memories/rag/traces?limit=20` | 查看候选 BM25、余弦、融合、重排分数和最终注入记录 |
| `PATCH /memories/conversations/{segment_id}` | 用 `raw_content` 和浏览结果的 `content_hash`（传入 `expected_content_hash`）修订归档；版本冲突返回 409 |
| `DELETE /memories/conversations/{segment_id}` | 删除该对话归档及其派生数据；不删除聊天事件日志或其他来源的同义事实 |

验证入口为 `scripts/e2e/nyx-p5-memory-rag-e2e.py`；`--real-model` 使用本地编码器及配置的回复模型，`--postgres` 仅可指向可丢弃的隔离测试库。探针使用临时目录，不应对业务数据库执行。

## 源码入口

- `nyx/research/`、`nyx/behavior/`：共用研究、行为反思、经验及角色独立的 skill 版本。
- `nyx/memory/facade.py`：记忆门面、资料摄入、批注反馈、经验与跨系统接线。
- `nyx/memory/segments.py`、`facts.py`：对话段与事实处理。
- `nyx/memory/conversation_chunks.py`、`conversation_retrieval.py`：对话切块、混合召回和原文片段溯源。
- `nyx/memory/conversation_indexing.py`：历史回填、版本重建与失败恢复。
- `nyx/memory/store.py`、`retrieval.py`、`ann.py`、`graph.py`：存储、检索和关系索引。
- `nyx/expression/prompt.py`：最终上下文选择与预算；`nyx/db.py`：迁移与事务。
