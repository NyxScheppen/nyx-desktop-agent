# How: 安全规范

## 原则

基础安全——防常见漏洞和泄露，不追求军工级防护。

## API Key 管理

- LLM API Key 通过 `.env` 文件注入环境变量，**绝不硬编码**在源码中
- `.env` 加入 `.gitignore`，不提交到版本控制
- 提供 `.env.example` 模板文件（含空值，不含真实 Key）

## 本地数据保护

- 所有对话记录、记忆数据、用户偏好存本地 SQLite
- 数据库文件放在用户目录下的应用数据文件夹（`~/.nyx/` 或平台等效路径）
- 用户可随时导出全部数据（JSON 格式）或一键删除
- 数据最小化原则——只存功能必需的数据

## 网络安全

- 出站请求仅允许：LLM API 调用
- 不上传用户数据到任何第三方服务器
- 所有 LLM API 请求使用 HTTPS

## 输入安全

- 用户输入不做服务端 HTML/JS 注入过滤（桌面端无浏览器渲染风险）
- LLM 返回内容在 UI 渲染前做基本清理

## 不涵盖

- 不实现端到端加密（本地应用，无传输需求）
- 不实现用户认证/多账户（单用户桌面应用）
- 不做企业级审计日志
