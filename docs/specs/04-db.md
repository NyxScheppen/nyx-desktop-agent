# SQLite 连接 + 建表 + 迁移

> 范围：`nyx/db.py`（`connect()` + `migrate()` + `Database` dataclass + `DEFAULT_DB_PATH` + `_MIGRATIONS`）。SQLite 连接、14 张业务表建表、版本化迁移。
> 纯基础设施 spec：只管「建库、建表、迁移」，不含任何 CRUD / 行↔dataclass 序列化（那是各 store spec 的活）、不含 Facade、不含 API。
> spec 只定义契约（连接/迁移签名 + 表清单 + 可空性约定）；完整 DDL 以 `nyx/db.py` 源文件为准。

## 元信息

- **前置依赖**：01-types（DDL 列名 / 枚举值 / 可空性语义对应其字段，但 `db.py` **不 import** 任何 `nyx` 模块，只依赖 `aiosqlite`）；不依赖 02-config（DB 路径走 env/默认，不入 config.yaml，见下）

## 用户故事

> 作为 Nyx 系统的开发者，我想要一份 SQLite 连接 + 14 张表建表 + 版本化迁移的单一入口，以便各子系统 store 用同一个注入连接做 CRUD、表结构与迁移历史可查、升级失败可原子回滚。

## 技术方案

- **新文件**：`nyx/db.py`（无 Facade、无 API、无业务逻辑）
- **库**：`aiosqlite`（异步 sqlite3 封装；满足 CLAUDE.md「I/O 操作用 async def」，后续 store 方法全 async）
- **公开面**：`from nyx.db import connect, migrate, Database, DEFAULT_DB_PATH`（不加 `__all__`；`_MIGRATIONS` 私有）
- **单连接 + 共享锁**：`connect()` 返回 `Database(conn, lock)`，组合根（`main.py`，归 18-api）启动时 `connect()` 一次，把 `Database` 注入各 store；store 的 DB 读写用 `async with db.lock:` 串行化（同一 `aiosqlite.Connection` 不能并发 execute/commit）。退出时 `await db.conn.close()`。store 不再各自 `aiosqlite.connect`
- **DB 路径**：`path > NYX_DB env > "nyx.db"`，与 02-config `load_config` 的 `path > NYX_CONFIG > "config.yaml"` 同款。路径是部署关注点，不进 config.yaml（避免重开 02-config）
- **pragma**：`foreign_keys=ON`（SQLite 默认关，不设则 `memory_edge` 的外键形同虚设）；`journal_mode=WAL`（崩溃安全 + 读写不互斥）
- **row_factory**：`aiosqlite.Row`（= `sqlite3.Row`），store 按列名取值 `row["id"]`，不按位置猜
- **版本化迁移**：`schema_version` 单行表记录当前版本；`_MIGRATIONS` 升序 `(version, [单条 SQL])`；`migrate()` 只套 `version > current` 的项
- **为什么原子**：非原子迁移（逐条裸 `execute`）若部分建表后失败，版本不推进 → 重启重跑撞「table already exists」（CREATE 无 IF NOT EXISTS）。原子事务（`BEGIN`/`COMMIT`/`ROLLBACK`）失败即整体回滚、版本不推进 → 重启干净重试
- **15 张表**：14 张业务表 + 1 张 `schema_version`（迁移簿记，不算业务）
- **复杂字段存 JSON 字符串**：`story` / `becoming` / `subtopics` / `progress` / `aspect` / `goal` / `linked_values` / `self_view` / `content` / `embedding` 在表里是 `TEXT` 列；`json.dumps`/`json.loads` 是各 store 的活，本 spec 只定列
- **枚举列存 `.value` 字符串**（`TEXT`），不存成员名——与 01-types「可直接 `json.dumps` / 存 SQLite」一致
- **可空性严格一一对应**：01-types 里 `X | None` ⟺ DDL 列可空。非 Optional 字段的列全 `NOT NULL`（空集合存 `"[]"`、空对象存 `"{}"`、`correlation_id` 恒填），store 序列化不必判 None；Optional 字段的列保持可空

**表 → 归属子系统**（store 各自 CRUD，连接由组合根注入）：

| 子系统 | 表 |
|---|---|
| inner_life | `personality` / `value_system` / `energy` / `self_narrative` |
| memory | `memory` / `memory_edge` |
| desire | `short_term_desire` / `desire_value` / `long_term_desire` |
| activity | `activity` / `material` |
| reading | `books` / `paragraphs` |
| events | `event_log` |

## 测试要点

- [ ] 单元测试 `tests/test_db/`（`pytest-asyncio`，`migrate` 逻辑用 `:memory:`，`connect` 的 WAL 用 `tmp_path` 文件——WAL 只在文件上生效，`:memory:` 上是 `"memory"`）：
  - [ ] `migrate` 全新建库（`:memory:`）：`sqlite_master` 里业务表 = 硬编码 14 张集合 + `schema_version` = 共 15 张；显式索引 = 5 个（`idx_memory_tag` / `idx_memory_type` / `idx_event_log_corr` / `idx_memory_content_hash` / `idx_books_content_hash`，`WHERE type='index' AND sql IS NOT NULL`）；`schema_version` 单行 = `_MIGRATIONS` 最高版本
  - [ ] 可空性对齐：`PRAGMA table_info(<表>)` 断言 5 列 `notnull=1`（`memory.aspect`、`long_term_desire.linked_values`、`activity.progress`、`event_log.content`、`event_log.correlation_id`）；Optional 列（`short_term_desire.goal` / `activity.ended_at` / `memory.embedding` / `memory.content_hash` 等）`notnull=0`
  - [ ] `migrate` 幂等：连跑两次不报错，表数不变、版本不变
  - [ ] `migrate` 版本门控/增量：先跑到当前最高版本；`monkeypatch` `_MIGRATIONS` 追加 `(next_version, ["CREATE TABLE foo (id TEXT PRIMARY KEY)"])`（`next_version = max(v for v, _ in db._MIGRATIONS) + 1`）再跑 → 只套 next_version，版本=next_version，已有表不重复建
  - [ ] `migrate` 原子回滚：`monkeypatch` `_MIGRATIONS = [(1, ["CREATE TABLE ok (id TEXT PRIMARY KEY)", "这不是合法 SQL"])]` → `migrate` 抛 `aiosqlite.Error`；`ok` 表不存在（回滚生效）；`schema_version` 仍为 0
  - [ ] `connect`（`tmp_path` 文件）：返回 `Database`；`db.conn` 上文件被创建；`PRAGMA journal_mode` 返回 `"wal"`；`PRAGMA foreign_keys` 返回 `1`；`row_factory` 生效（`SELECT 1 AS x` → `row["x"] == 1`）；`db.lock` 是 `asyncio.Lock` 实例
  - [ ] `connect` 路径解析：显式 path 优先（`connect(tmp_path/"a.db")` 建 a.db）；`path=None` 时 `monkeypatch.setenv("NYX_DB", ...)` 覆盖默认（建 env 指定文件）；`DEFAULT_DB_PATH == "nyx.db"`
  - [ ] `connect` 错误路径不泄漏：`monkeypatch` `migrate` 抛 `aiosqlite.Error` → `connect` 抛异常且连接被 `close`（spy 连接记录 `close` 被调用）
- [ ] 集成测试：无（无 Facade 管道）
- [ ] E2E 测试：无
